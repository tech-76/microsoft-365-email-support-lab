# Microsoft 365 and Email Support Lab

This repository documents email support concepts and troubleshooting steps for Microsoft 365, Outlook, Thunderbird, SMTP, IMAP, DNS records, and mail flow issues.

## Topics Covered

- Outlook troubleshooting
- SMTP, IMAP, and POP3 basics
- Microsoft 365 mail flow
- Exchange Online support concepts
- DNS records for email
- SPF, DKIM, and DMARC awareness
- Thunderbird desktop email client setup
- Website form email delivery troubleshooting

## Skills Demonstrated

- Email troubleshooting
- Microsoft 365 support
- DNS record awareness
- Mail delivery troubleshooting
- Technical documentation
- Customer-focused support
